# Sorigul

소리글(Sorigul)은 Windows용 음성 전사 및
전사 결과 관리 데스크톱 애플리케이션이다.

Greenfield 프로젝트이며
현재는 UI/UX First 방식으로 개발한다.

기존 전사도우미 소스는 신규 프로젝트 dependency가 아니며,
기능 요구사항 참고자료로만 취급한다.

현재 Phase:

Project Foundation / Design System v1

관련 공식 문서:

docs/project/
docs/design/

현재 실제 transcription 기능은 구현하지 않는다.

## Frontend

- React
- TypeScript
- Vite

현재 상태:
- Frontend Foundation
- 실제 transcription 기능 없음
- UI/UX First 진행 중

Frontend 실행 방법:

```
cd frontend
npm install
npm run dev
```

Frontend 검증:

```
npm run lint
npm run build
```
