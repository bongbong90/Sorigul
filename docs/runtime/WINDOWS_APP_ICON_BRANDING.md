## Canonical master decision

SHA-256:

`38ca2d8f0aec3409cf9a57f60ed86d26881eace76476803a05c4ffa7a8fab612`

  - 1024 x 1024 RGBA, canonical motif position retained
- `docs/design/reference/app-icon-v1-transparent-runtime.png`
  - SHA-256: `07577961e495d1dbc786b7b5367f3cdc67731f3f9c91bd37ca8a92c33f62819a`
  - 1024 x 1024 RGBA, transparent canvas
  - canonical motif scaled to an 880 x 476 safe area and centered

The white matte was removed deterministically. Opaque Quiet Teal source pixels remain opaque;
anti-aliased edge pixels retain alpha; near-white canvas noise below 4% recovered opacity is
discarded. A white recomposite of the position-preserving derivative differs from the canonical by
only 0.0311/255 mean absolute channel error overall (0.0944/255 in the motif region). The runtime
derivative changes padding only; it does not redraw or recolor the canonical motif.

An AI background-removal candidate was evaluated and rejected because it changed canvas size,
geometry, color, and opacity. It is not part of the repository or the generated asset chain.

## Placeholder root cause

The original khaki/solid-square result came from Tauri assets generated from a temporary solid
`#3E6874` placeholder master. Every old PNG and ICO frame contained the same single opaque color.

This was a wrong source asset issue. It was not a Tauri configuration error, malformed ICO
container, alpha defect, Windows rendering problem, stale tray registration, or tray lifecycle
defect.

## Pixel-native small surfaces

A direct downsample of the wide canonical motif failed actual taskbar and tray review: at 16–24px
the motif collapsed into a faint horizontal mark. Merely increasing alpha or scaling the source did
not make Audio Waveform -> Text Lines identifiable.

After official Tauri generation, the reproducible small-surface tool is run:

```text
python -m pip install -r tools\requirements-icons.txt
python tools\windows_icon_small_surfaces.py
```

The tool verifies the canonical and transparent-runtime SHA-256 values before writing assets. For
16, 24, 32, 48, and 64px surfaces it renders the same brand contract as a pixel-native glyph:

- five rounded audio-waveform bars on the left
- three separated text lines on the right
- Quiet Teal `#3E6874` core
- one-pixel offset Primary Soft `#DCE9E9` underlay for dark Windows chrome contrast
- fully transparent remaining canvas; no color tile

The underlay is part of the small raster treatment, not a background and not whole-icon opacity.
It prevents the Quiet Teal glyph from disappearing against dark taskbar/tray chrome. The 256px ICO
frame and large PNG assets remain canonical transparent derivatives.

Small PNGs post-processed by the tool are `32x32.png`, `64x64.png`, `StoreLogo.png`,
`Square30x30Logo.png`, and `Square44x44Logo.png`.

## Tauri wiring

## Known risks

- Windows may cache icons for reused executable paths. The runtime smoke used clean crate builds,
  and the release EXE was deleted before rebuilding; no global cache was removed.
- The 16–64px glyph is intentionally pixel-native rather than a direct geometric downsample. This
  is required to preserve the approved motif at Windows chrome sizes.
- Installer-specific propagation remains deferred until an installer is produced.
