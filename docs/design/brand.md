# 소리글 (Sorigul) 브랜드 가이드라인

## 1. 브랜드 개요
- **이름**: 소리글 (Sorigul)
- **메시지**: 소리를 글로.
- **성격**: Quiet, Calm, Focused, Premium, Professional.
- **지향점**: 현대적인 데스크톱 생산성 도구 (Modern Desktop Productivity).

## 2. 시각적 정체성
- **심볼**: 오디오 파형(Audio Waveform)에서 텍스트(Text Lines)로의 전환을 형상화.
- **컬러**: Quiet Teal (#3E6874)을 중심으로 한 저채도 팔레트.
- **언어**: 한국어 중심의 인터페이스 (Pure Korean UI).

## 3. 금지 사항
- **Legacy 명칭 사용 금지**: 전사도우미, Jeonsa Doumi 등 이전 명칭 노출 금지.
- **의료용 파형(ECG) 금지**: 뾰족한 지그재그 형태 대신 부드러운 오디오 파형 사용.
- **과도한 장식 금지**: 그라데이션, 그림자, 애니메이션 최소화.
