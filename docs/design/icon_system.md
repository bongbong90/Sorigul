# 소리글 (Sorigul) 아이콘 시스템 (v1 Final)

## 1. 시각적 스타일
- **스타일**: Simple Outline (외곽선)
- **두께**: 1.5px ~ 2px (일관된 선 두께)
- **형태**: Rounded Geometry (부드러운 곡선)

## 2. 주요 아이콘 분류
- **Navigation**: 전사, 대시보드, 결과, 설정
- **Actions**: 폴더 선택, 시작, 중지, 새로고침, 편집, 삭제
- **Status**: 완료, 실패, 경고, 진행 중, 중지

## 3. 브랜드 심볼
- **컨셉**: 오디오 파형이 점진적으로 정돈되어 텍스트 라인으로 변하는 연속적 심볼.
- **제약**: 16px 수준의 작은 크기에서도 Waveform과 Text Line의 구분이 명확해야 함.
- **금지**: 지그재그형(의료용), 마이크 단독 형태, 텍스트 포함.
