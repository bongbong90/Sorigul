# 소리글 (Sorigul) 컬러 시스템 (v1 Final)

## 1. Core Palette
| Token | Hex | Usage |
| :--- | :--- | :--- |
| **Background** | `#F3F5F4` | 앱 전체 배경 |
| **Surface** | `#FAFBFA` | 카드, 사이드바 배경 |
| **Surface Soft** | `#EDF2F1` | 보조 영역, 비활성 배경 |
| **Surface Hover** | `#E7ECEB` | 호버 상태 배경 |
| **Border** | `#D6DEDC` | 기본 구분선 |
| **Border Strong** | `#C4CFCC` | 강조 구분선, 활성 테두리 |
| **Text Primary** | `#223035` | 주요 헤딩, 본문 라벨 |
| **Text Secondary** | `#667479` | 보조 텍스트, 설명문 |
| **Text Muted** | `#899397` | 플레이스홀더, 비활성 텍스트 |
| **Primary** | `#3E6874` | 브랜드 컬러, 주요 액션 |
| **Primary Hover** | `#345A64` | 버튼 호버 |
| **Primary Soft** | `#DCE9E9` | 활성 네비게이션/행 배경 |
| **Primary Pressed** | `#2E4D55` | 버튼 클릭 |

## 2. Semantic Status (Muted Palette)
- **대기 (WAITING)**: `#5F6B6F` / `#ECEFEE`
- **준비 중 (PREPARING)**: `#536C7D` / `#E5EDF1`
- **전사 중 (TRANSCRIBING)**: `#3E6874` / `#DCE9E9`
- **저장 중 (SAVING)**: `#625A77` / `#ECE8F0`
- **완료 (DONE)**: `#466850` / `#E3EEE6`
- **실패 (FAILED)**: `#8F504B` / `#F3E5E3`
- **중지됨 (CANCELLED)**: `#7D603B` / `#F1E9DD`
